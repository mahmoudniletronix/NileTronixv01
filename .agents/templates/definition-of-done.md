# Definition of Done — proportional to task
- [ ] Requested behavior implemented, no unapproved scope expansion.
- [ ] Business rules / role/tenant restrictions verified.
- [ ] API contract and side effects confirmed or clearly blocked.
- [ ] Critical success/failure/empty/loading/error cases handled.
- [ ] Desktop, tablet, mobile UX fit the actual workflows where visual.
- [ ] Accessibility + i18n/RTL/LTR checked where relevant.
- [ ] Targeted typecheck/tests run; broader tests based on change risk.
- [ ] No unrequested secret/dependency/production change.
- [ ] Final evidence includes command, actual outcome and unverified limits.
