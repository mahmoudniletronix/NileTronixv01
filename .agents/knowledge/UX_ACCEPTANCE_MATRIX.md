# Cross-device product UX acceptance matrix (adapt, don't apply mechanically)

| Dimension | Desktop | Tablet | Mobile |
| --- | --- | --- | --- |
| Core job | efficient deep work | touch + overview | fast task completion |
| Navigation | expanded or contextual | condensed/contextual | task-specific top/bottom/drawer as justified |
| Tables | scan/sort/filter/comparison | priority columns/details | structured items + drill down OR true compare scroll if necessary |
| Filters | visible when useful | collapsible as needed | sheet/compact controls, selected count/clear |
| Forms | grouped and efficient | touch adequate | correct keyboard, focused steps when warranted |
| Dialogs | accessible modal/side panel | responsive dialog/sheet | sheet/full-screen where appropriate, keyboard safe |
| Feedback | status/error near action | same | recoverable inline or nonblocking feedback |
| Internationalization | bidi, long labels | bidi + space | bidi + small widths |
| Accessibility | keyboard/focus/semantic | keyboard/touch | focus, target size, screen reader, zoom |

Test at content-driven sizes; record viewport, route, language, role and observed results. Never claim manual assistive-tech testing without it.
