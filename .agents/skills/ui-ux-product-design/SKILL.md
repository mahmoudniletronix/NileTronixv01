# Senior product UI/UX — solve workflow, not decoration
1. Observe actual user/role, task success criterion, friction, frequency, urgency, data density and constraints (B2B/B2C, tablet, shared workstation etc.).
2. Inspect existing page, brand system, repeated components and real content. Form a small issue list by severity; cite code/screenshots when available.
3. Plan hierarchy, affordances, copy, navigation, errors, empty/no-results, permissions, key interactions and information reveal.
4. Prefer useful tables for large data, lists for scanning, forms for transactions, and contextual detail panels over endless nested cards. Don't impose trendy patterns.
5. Implement using current framework and design tokens. Preserve functionality and localization; avoid visual identity drift.
6. Review key task end-to-end on keyboard, touch and different viewport sizes. Compare screenshots only when actual browser tool available.

### Decision rule
On desktop optimize density/productivity; on mobile optimize task path/reach. Accessibility and discoverability outrank purely aesthetic preferences.
