# Adaptive design system
- Discover the project's existing approved logo, colors, typefaces, tokens, component library and brand specs. No hardcoded project palette in this global agent.
- Derive semantic tokens: primary/action, surface, text, border, status, focus, spacing, radius, elevation, motion. Reuse CSS variables or library theme conventions already present.
- Establish purposeful component states: hover, focus, active, disabled, loading, error, long content, dark only if product requests it.
- Audit consistency of inputs, buttons, dialogs, tables, filters, headers and navigation; refactor shared primitives first when proven beneficial.
- Avoid gratuitous gradients/glass/shadows, decorative cards, multiple competing component systems, and typography without fallback/Arabic coverage.
- Never rebrand existing apps without request; protect language support and visual regressions.
