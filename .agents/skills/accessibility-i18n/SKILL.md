# Accessibility and localization practice
- Semantic headings, navigation and landmarks; labels/instructions, field/error association; keyboard operability/focus management; contrast and reduced motion.
- Handle overlay/dialog focus, live errors/announcements and virtualized lists accessibility.
- Respect project translations; inspect pluralization, truncation, mixed Arabic/Latin, RTL icon direction, logical CSS properties and date/time formatting.
- Test mobile zoom, dynamic text and on-screen keyboard alongside keyboard-only desktop.
- Automated axe/Playwright/Lighthouse reports help but do not replace human/assistive-tech checks. Don't claim WCAG certification.
